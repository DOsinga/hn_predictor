Hacker News submitters get two levers before the crowd takes over: the title and the URL. This project is setting up a prediction model around exactly those inputs.

The prediction button is intentionally disabled until there is a trained model wired into the page. The current model path is a small local embedding network trained on title and URL text, with log1p(points) as the target. The strongest current version uses a frozen pretrained English text embedder plus a small neural regression head.
